# Deployment quickstarts

Thaum ships optional **deployment guides** under `quickstart/`. They are examples and templates, not the only way to run the app.

| Topic | Location |
|--------|----------|
| **Atlassian / Jira Cloud** (site id, org id, API token, permissions) | [Atlassian-Jira.md](Atlassian-Jira.md) |
| **Commercial cloud** (Azure Container Apps and future clouds) | [Thaum Cloud](https://gemstone-software-dev.github.io/thaum-cloud/) ([template repo](https://github.com/gemstone-software-dev/thaum-cloud)) |
| **Kubernetes** (any distro: on-prem, EKS, GKE, AKS, …) | [quickstart/kubernetes/README.md](https://github.com/gemstone-software-dev/Thaum/blob/main/quickstart/kubernetes/README.md) |

The main entry point for all quickstart paths is [quickstart/QUICKSTART.md](https://github.com/gemstone-software-dev/Thaum/blob/main/quickstart/QUICKSTART.md).
